# Security Policy

## Supported Versions

Only the current state of the default branch is supported. Fixes are not backported.

## Reporting a Vulnerability

Please **do not** open a public issue for security problems.

Use GitHub's private vulnerability reporting instead:

1. Open the [Security tab](https://github.com/TyMi/backupFTP/security) of this repository.
2. Click **Report a vulnerability**.
3. Describe the issue, the affected component and, if possible, steps to reproduce it.

The report stays private between you and the maintainer until a fix is available.
This is a hobby project maintained in spare time, so please allow some time for a first
response (typically within a few days).
